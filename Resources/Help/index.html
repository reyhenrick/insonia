Install and start

  1. 1Move Insonia to Applications.

    Open the downloaded Insonia-macOS.dmg and drag Insonia to Applications. Open the app from Applications, then eject the disk image. Using the ZIP instead? Unzip it and move the app to the same folder.

  2. 2Allow the first opening if macOS asks.

    Follow the first-opening instructions below if macOS asks you to approve the app.

  3. 3Turn on Keep awake.

    Click the lightning bolt in the menu bar and turn on Keep awake. Insonia prepares what it needs automatically and asks for administrator approval through macOS when required.

  4. 4Confirm and start your work.

    Approve the prompt and wait for activation to be confirmed. If you cancel, Keep awake stays off; turn it on again when you want to retry. Right-click the menu bar icon to toggle Keep awake without opening the panel.

First opening

This release is signed ad hoc and has no Apple Developer ID signature or notarization. If you trust the download and macOS blocks its first launch, go to System Settings → Privacy & Security → Open Anyway and confirm Open. This creates an exception for Insonia. A managed Mac may restrict this option.

If macOS says the app is damaged or will harm your computer, stop and download a fresh copy from the repository's Releases page. Report a persistent problem. Follow Apple's instructions for downloaded apps; do not disable macOS security checks.

This guide is included in the disk image as README-install.html and can be opened in your browser.

Automatic recovery

Recovery is part of Insonia's normal operation. It restores normal sleep and saved display brightness when a session ends or the app stops responding. Insonia prepares its services when you turn on Keep awake and confirms they are ready before starting the session.

Insonia manages those services automatically. If it needs administrator approval to complete setup, macOS shows its native authorization prompt. Cancelling leaves Keep awake off until you explicitly turn it on again.

Choose your mode

Keep awake
Keep background tasks running, including with the lid closed. With agent access turned off, the display can sleep.
Allow agents to use the display
Preserve an already unlocked graphical session. Enable this option with the lid open and the Mac unlocked, then turn on Keep awake. Closing the lid dims the built-in display to at most 1%; reopening the lid or ending the session restores its saved brightness. External displays are not dimmed.
Open at login
Open Insonia when you sign in. This preference does not enable Keep awake on its own.
Start active
Request Keep awake when Insonia launches. After a protective cutoff, start the next session yourself; the app does not silently reactivate it.

You stay in control of your session

Insonia does not unlock the Mac, enter passwords, or change FileVault. Manual locking, user switching, or a system policy can pause visual access. Screen Recording and Accessibility permissions belong to the agent that uses them. Test a real capture, click, and typing action with your agent before relying on closed-lid display access.

When Insonia pauses a session

Insonia stops keeping the Mac awake at 15% battery or less when unplugged, when the battery cannot be checked while unplugged, or when macOS reports serious or critical thermal pressure. It also stops when recovery services cannot maintain a healthy session. Connect power or let the Mac cool down before starting another session.

Recovery timing depends on macOS scheduling. Keep an active Mac on a ventilated surface, outside a closed bag. Agent mode depends on macOS and the hardware; private display interfaces may change in future updates. An Intel build is included, but physical Intel validation is separate from compilation.

Stay up to date

Insonia checks for new versions automatically while it is open. Choose Check for updates… in the panel to check immediately. When a new version is found, the button reads Update available and a blue dot appears on the menu bar icon. By default, you choose when to install an available version.

To receive and install future releases automatically, open the panel's … menu and enable Install updates automatically. A ready update waits until Keep awake is off and normal sleep and brightness have been restored. Turn off Keep awake when your work finishes to allow installation. Updates also wait for setup to finish.

The first launch after an update starts with Keep awake off. Turn it on when you want a new session. Your Start active preference remains saved for later launches.

Updates come from GitHub Releases. Insonia verifies the update feed and downloaded archives with the project's Ed25519 signing key before installation. If a release needs additional setup, Insonia handles it the next time you turn on Keep awake and asks for macOS approval when required.

Your language, automatically

The app supports English, Portuguese, Spanish, French, German, and Italian. It follows your macOS language preferences and falls back to English when none matches.

To change the preferred language, open System Settings → General → Language & Region, adjust your preferences, and reopen Insonia. This guide and the repository documentation are in English.

Get back to work

Read the status in the panel before starting a new session.

The recovery monitor lost its signal

Insonia turned off Keep awake and is restoring normal behavior. A Previous interruption message describes what happened; the current status shows whether recovery is still in progress.

Leave Insonia running while it completes recovery. When you are ready, turn Keep awake on again; the app checks its services before starting the session. If the problem repeats, report it with the app version, macOS version, and the message shown.

The agent cannot see or control the display

Open the lid and unlock the Mac. Check that Allow agents to use the display is enabled and that the agent has its own Screen Recording and Accessibility permissions. Then test again with the lid closed.

Manual locking or a system policy can pause visual access. A background task still running does not prove the graphical session is available. If the panel reports an unavailable display, reopen the lid.

Insonia stopped while on battery or when the Mac was warm

This can be a safety cutoff. Connect power or let the Mac cool down, check the reason in the panel, and turn Keep awake on again when you are ready. Insonia does not automatically restart after this interruption.

I cannot find the app window

Insonia is a menu bar app. Open it from Applications, then click the lightning bolt at the top of the screen. It does not require a permanent Dock icon. If it cannot open, follow the first-opening instructions above.

I cancelled the administrator prompt

Keep awake stays off. Turn it on again when you want to retry, approve the native macOS prompt, and wait for activation to be confirmed. Insonia does not keep reopening the prompt after cancellation.

Open Insonia from Applications before turning on Keep awake. An app still running from the disk image must be moved there first.

An app update is ready but has not installed

Finish your current work and turn off Keep awake. Installation waits for normal sleep and brightness recovery to finish. If the panel shows a problem, resolve it first. Open Insonia from Applications to use the updater.

Automatic installation is a separate preference in the … menu. When it is off, choose Update available or Check for updates… and confirm installation yourself.

How can I check a download?

Download SHA256SUMS.txt from the same release. In Terminal, open the folder containing your download and run:

shasum -a 256 Insonia-macOS.dmg

Compare the result with the line for that filename. A matching hash verifies the downloaded bytes. It is not Apple notarization.

Remove Insonia

Follow the complete removal procedure to restore normal sleep, remove Insonia's background services, and delete the app.

Keep Insonia in Applications until the background services have been removed; the procedure uses the uninstaller bundled with the app.

Make Insonia better

Insonia is open source under the MIT license. Bug reports, translations, documentation improvements, and code contributions are welcome.

To build from source, use Xcode with a macOS 26 SDK or newer. Start with the contribution guide, then run these commands from your clone:

./test.sh
./build.sh
scripts/package-release.sh

The build creates build/Insonia.app with the Sparkle updater. Packaging creates the DMG, app-only ZIP, checksums, and signing metadata in dist/ without publishing or installing the system helper. The contribution guide covers the separate local signing and release process.

Privacy and network access

Power control and recovery run locally. Insonia needs no account and collects no analytics. The updater connects to GitHub and its release-download infrastructure to check for and download new versions. System profiling is disabled. The hosting service receives ordinary request metadata, such as your IP address.

Recovery records stay on your Mac and contain power and session events, not screenshots or window contents. Links you choose to open use your browser.

Report a problem or suggest an improvement. For a security vulnerability, use the private reporting channel.

Insonia is a community project. Documentation is in English; the app follows your Mac's language.
